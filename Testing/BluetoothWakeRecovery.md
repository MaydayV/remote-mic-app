# 蓝牙睡眠唤醒恢复

## 目标

系统睡眠后，蓝牙遥控器连接应在应用真正恢复运行时重新建立；如果 CoreBluetooth 已自行恢复，则不应再次拆掉健康连接。

## 验证步骤

1. 连接小米遥控器并确认按键与语音均可用。
2. 让 Mac 进入系统睡眠后唤醒，等待系统与应用恢复；预期遥控器自动恢复，日志只出现一次 `BLE WAKE recovery_begin`。
3. 仅关闭并唤醒显示器，不让 Mac 进入系统睡眠；预期不触发蓝牙重连。
4. 在短暂睡眠后确认蓝牙已自行恢复时再观察应用恢复；预期日志出现 `recovery_skipped reason=bridges_already_ready`，不重复拆连。
5. 睡眠期间退出应用并重新启动；预期不会使用上一轮挂起状态，应用按正常发现流程连接。

## 自动化与边界

- `BluetoothLifecycleTests` 和 `BluetoothWakeRecoveryPendingTests` 覆盖挂起状态、显示器唤醒隔离、已恢复连接保护及未观察到睡眠通知的唤醒。
- 单元测试不替代真实 macOS 睡眠/唤醒和蓝牙硬件验收；必须在至少一台实际遥控器上完成步骤 1–4，并检查运行日志。
