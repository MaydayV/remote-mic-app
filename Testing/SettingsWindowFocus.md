# 设置窗口与 Dock 图标

适用版本：下一包含此修复的版本（预计 `1.8.15+`）

## 准备

1. 启动无线麦并完成首次设置。
2. 在“关于”页关闭“显示 Dock 图标”。
3. 确认菜单栏图标仍然存在。

## 用例

1. 打开设置窗口：窗口应显示，Dock 图标应出现。
2. 点击红色关闭按钮或按 `Command-W`：窗口应关闭，菜单栏图标仍保留，Dock 图标应隐藏。
3. 从菜单栏重新打开设置：窗口和 Dock 图标应重新出现。
4. 打开“显示 Dock 图标”后关闭设置窗口：Dock 图标应继续显示。
5. 使用“退出无线麦”或 `Command-Q`：菜单栏图标和进程都应退出。

失败判定：关闭设置窗口后菜单栏图标消失、Dock 图标状态与开关不符、或重新打开设置失败。

自动化测试覆盖 activation policy 计算和窗口关闭代理；真实 macOS 窗口、菜单栏和 Dock 行为需要在真机验收。
