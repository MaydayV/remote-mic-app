# 切回上个 App

## 验证步骤

1. 在设置的按键映射中，把任一遥控器按键的单击动作设为“切回上个 App”。
2. 打开两个不同的前台 App，按一次遥控器按键；预期发送一次完整的左 Command + Tab 按下/释放序列并回到上一个 App。
3. 长按或快速连按同一按键；预期每次完整触发一次，不打开持续的 App 切换器，也不重复执行定时连发。
4. 暂时关闭辅助功能权限后再次触发；预期不发送按键并显示权限恢复提示。

## 自动化与边界

- `RemoteButtonsTests` 覆盖按下/释放顺序、失败时仍释放 Command、非重复属性和本地化。
- 自动化只验证事件序列；真实前台 App 切换和权限提示仍需在 macOS 实机验收。
