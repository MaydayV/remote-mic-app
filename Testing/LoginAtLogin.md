# 登录时自动启动测试手册

## 自动化覆盖

`LoginItemServiceTests` 覆盖默认关闭、注册、取消注册、系统要求批准、打开系统设置入口和注册失败反馈。

## 手动验收（macOS 13+）

1. 在“关于”页面确认“登录时自动启动”默认关闭；开启后检查“系统设置 → 通用 → 登录项与扩展”中出现无线麦。
2. 在系统设置中要求批准时，确认页面显示提示并能打开正确的登录项页面；批准后回到应用，状态应刷新。
3. 关闭开关并注销/登录，确认应用不会自动运行；重新开启后注销/登录，确认菜单栏应用自动运行。
4. 分别验证“显示 Dock 图标”和“启动时自动打开主面板”不受影响。

## 边界

构建和单元测试不能证明真实注销/登录行为；必须在真实 macOS 用户账户中完成开启、批准、关闭和再次登录验收。日志仅记录登录项操作结果，不应包含敏感信息。
