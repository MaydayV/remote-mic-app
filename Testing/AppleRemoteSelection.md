# Apple Siri Remote 图片选择卡片

适用版本：下一包含此修复的版本

1. 打开设置 → 连接。
2. 在“连接设备”区域选择 Apple Siri Remote。
3. 预期：卡片左侧显示 Apple Siri Remote 的真实遥控器图片，不显示 Apple 标志图标。
4. 切换回小米遥控器：小米卡片和原有连接状态、语音提示保持不变。
5. 在浅色和深色外观下重复步骤 2–4，图片不应变形、裁切或遮挡文字和选中状态。
6. 分别点击卡片的标题、状态区域、图片周围和卡片边缘，均应切换遥控器，不需要精确点中文字。

授权提示验收：首次启用原生 Apple Remote 语音捕获时，授权对话框应跟随系统语言显示中文或英文，
不应出现与系统语言混用的固定中文文案。

失败判定：Siri Remote 卡片仍显示 `apple.logo`、图片无法加载且没有明确回退，或切换后连接状态/语音设置被改变。

自动化测试覆盖资源名称和视图分支；真实窗口比例和外观仍需在 macOS 真机验收。
