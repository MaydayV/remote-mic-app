# 上游预览版功能同步验收

适用范围：Remote Mic 上游预览版功能移植（输入框聚焦改进）。

## 自动化验证

- `swift test`
- 重点覆盖 `RemoteButtonsTests` 中的 `focusInput`、搜索框、设置框和 Terminal 输入区候选排序。

## 手工验收

1. 在按键映射中将任意按键的单击动作设为“聚焦输入框”。
2. 在聊天应用的搜索框、设置值输入框和 Terminal 输入区分别触发该按键。
3. 预期：对应输入区获得焦点；密码、令牌、API Key 等敏感字段不会被自动聚焦。
4. 撤销辅助功能权限后再次触发，预期动作失败且不会发送模拟按键。

## 回归边界

- 小米遥控器蓝牙语音、苹果 Siri Remote 按键/原生语音、Command-Tab、滚动动作和已有自定义 App 聚焦路径不应改变。
- 搜索框、设置框和 Terminal 的真实 macOS Accessibility 树仍需在目标应用版本上人工验收；自动化测试不替代真机流程。
